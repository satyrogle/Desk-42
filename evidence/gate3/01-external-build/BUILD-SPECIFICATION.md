## Acceptance standard

Before any build is distributed externally, it must pass all of the following:

- [ ] Installs and launches without developer tools
- [ ] A new player can understand how to begin
- [ ] The core gameplay loop is playable from beginning to a meaningful endpoint
- [ ] No known progression-blocking bugs
- [ ] Controls are presented clearly
- [ ] Resolution/window behaviour is acceptable
- [ ] Basic audio levels are consistent
- [ ] The player can exit normally
- [ ] Build version is visible somewhere in-game
- [ ] Testers have a clear feedback route
