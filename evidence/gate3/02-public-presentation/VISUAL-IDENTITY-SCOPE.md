# Desk 42 — Visual Identity and Copy Scope (Gate 3)

## Visual identity direction

**Retro-futuristic bureaucratic corporate surrealism + pixel-art presentation**

The objective is to remove anything that makes the game look unfinished, not to rebuild every visual asset before testing.

## Art priority tiers

### Priority A — What every player sees

- [ ] Main menu
- [ ] Opening screen
- [ ] Primary gameplay environment (the desk)
- [ ] Main character/player representation
- [ ] Core recurring objects (claims, dials, punch cards)
- [ ] Important UI elements
- [ ] End/completion state

### Priority B — What Steam visitors see

- [ ] Key art
- [ ] Logo treatment
- [ ] Strong screenshot compositions
- [ ] Capsule-ready visual material

### Priority C — Polish

- [ ] Secondary assets
- [ ] Minor environmental variation
- [ ] Decorative elements

## Copy scope

- [ ] One-line pitch
- [ ] Short Steam description
- [ ] Long Steam description
- [ ] Feature list
- [ ] Controls/instructions
- [ ] Playtest introduction text
- [ ] Survey language (see `03-playtesting/methodology/SURVEY-TEMPLATE.md`)
