# Codex Task 03 — Review Pass B1

Audit the Bureau Operations Console as a rendered interaction, not only as source code.

Use `docs/ACCEPTANCE_TESTS.md` and reject the implementation if it still resembles:

- thirteen cards
- ordinary vertical tabs
- a settings sidebar
- a literal floor-plan diagram
- a dense dashboard where route effects compete with the artwork

Test every division, keyboard navigation, rapid selection, mobile selector scrolling, theme switching, reduced motion, JavaScript-disabled fallback, and route recalculation.

Verify all counts and dependency facts against the repository.

If the implementation fails any acceptance requirement, fix it and rerun the full B1 matrix. Do not begin B2 or B3.
