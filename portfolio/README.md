A two-page, art-directed web portfolio presenting the systems architecture of
**Desk 42** (a solo-developed Unity roguelite) as a retro-futuristic bureaucratic
**control system**. Prepared as Global Talent Visa evidence for Sanjay Jacob
Sulegonker.

## View it
Open `index.html` in any modern browser — no build step. Boot once per tab
(shared `sessionStorage` flag), then explore. The **Systems Architecture**
dossier is the live deck; the other five are deliberately sealed / in-production.

## Tokens & themes
`tokens.css` is the single source of truth — a four-tier system (primitive →
semantic → component → scene), the named blooming-gradient set, motion durations
and easings. Two **authored** themes: **Night Shift** (dark) and **Archive Shift**
(aged institutional paper, not a white flip). Legacy `eng.css` variables
(`--bg-*`, `--fg-*`, `--mono`, `--t-*`, `--r-*`, …) are **remapped** to the formal
tokens in `pixel.css`, and fonts load once (Space Grotesk · IBM Plex Mono ·
Silkscreen). The hero title stays light over the dark stage in **both** themes.

## Pixel art
Three original raster scenes (`assets/pixel/`, generated by `tools/genart.py`):
`operator-night` (architecture hero), `bureau-vista` (index hero),
`anomaly-corridor` (anomaly beat). Rendered at 256×144, nearest-neighbour
upscaled. The three-layer stack is **raster pixel scene → SVG overlay → CSS
light/bloom/grain**. SVG is used for emblems, seals and diagrams; CSS for
atmosphere and motion. See `assets/MANIFEST.md`.

## Accessibility & performance
WCAG-AA target: one `h1`/`main`/`header` per page, alt text on all images,
focus-visible rings, status by label+shape, `aria-pressed` theme toggle, mobile
section nav (scrollable row), and full `prefers-reduced-motion`. Body-text
contrast ≈17:1 dark / 8.6:1 light. Continuous animations **pause** off-screen and
when the tab is hidden. Inline styles: architecture 7, index 2.
