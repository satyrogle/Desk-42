# Art Direction Guardrails

## Core statement

Desk 42 should feel like a haunted institutional control machine, not a portfolio website wearing a skin.

## Visual hierarchy

For the Bureau Operations Console:

1. Live bureau diorama
2. Selected dossier
3. Division switchboard
4. Signal routes and state effects

The artwork and spatial response create the wow moment. The route animation supports them; it is not the main attraction.

## Required qualities

- strong silhouettes
- controlled pools of light
- layered foreground, middle-ground, and background
- physical-looking switches, cabinets, pneumatic systems, monitors, paper, cables, and institutional signage
- pixel-art soul with high-fidelity composition
- subtle impossible architecture
- readable and deliberate use of negative space
- increasing unease without reducing usability

## Avoid

- generic cyberpunk
- random neon
- glassmorphism
- generic SaaS cards
- ordinary tab components
- literal floor-plan diagrams
- thirteen simultaneous animations
- procedural repetition visible at display size
- fake technical data
- long typewriter effects
- decorative charts used as visual filler

## Pixel-art acceptance threshold

A new hero or diorama asset is not acceptable merely because it exists at a higher resolution. At normal display size it must contain authored environmental detail, distinct lighting zones, varied machinery, non-repeating props, institutional markings, environmental wear, character presence, and restrained impossible details.

## Corruption progression

Static corruption remains for reduced-motion users. Motion reduction removes flicker, shake, parallax instability, repeated glitching, and route travel—not the narrative meaning.

Corruption must never alter factual evidence.
